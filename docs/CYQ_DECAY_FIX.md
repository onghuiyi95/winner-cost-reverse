# 火焰山绘制修正 — 换手衰减是关键 (2026-08-18)

## 用户反馈
"验证结果三版一致和原版差别太大, 获利盘完全不一样"
原版(用户截图): 获利盘 93.88% / 套牢 6.12%
我之前三版: 获利盘 72.86% / 57.18% (差 20+ 个百分点) -> 错误

## 根因诊断 (铁证)
用新浪 pufa_sina.csv (不复权, 2018-2026) 对比:
- 截止20210312, (H+L)/2成本, 无衰减: 获利盘 57.18%
- 截止20210312, (H+L)/2成本, decay=0.99: 89.91%
- 截止20210312, (H+L)/2成本, decay=0.98: 95.91%
- 截止20210312, (H+L)/2成本, decay=0.95: 96.66%

=> **差异主因 = 缺"远期换手衰减"**, 不是数据源!
通达信CYQ标准: 久远成交权重按 decay^(距今天数) 指数衰减
  无衰减: 远古筹码等权 -> 获利盘被稀释到57%
  加衰减: 远期权重趋零 -> 获利盘聚焦近期 -> 96% (接近原版93.88%)

## 成本取价
(H+L)/2 比 收盘价 更接近 (wuchang qingYu 已验证 (high+low)/2)
但本案例三种成本价(收/(H+L)/2/(H+L+C)/3) 结果都~57%无衰减, 差别小
衰减才是关键开关

## 精确对齐待确认
用户图: 成本分布日期20210312 + 当前价8.97 + 获利93.88%
- 但浦发 20210312 真实收盘(新浪不复权)=11.03, 非8.97
- 8.97 出现在 2021-08-30(收8.96)/2021-10-27(收8.99) 等更晚日期
- 用 8.97 游标算截止20210312分布 -> 0.00% (游标远低于历史成本)
=> 用户图"当前价8.97"与"成本分布日期20210312"可能:
  (a) 不同复权口径 (前复权后8.97是高位)
  (b) 图非浦发(虽vision标600000) 或 日期标签为基准日非计算截止
- N天前序列: 原版 100天前48.92% 远低于我 81.65% -> decay或游标定义需微调

## 结论
机制已修正: 加 decay(默认0.98) 后 57%->98.4% 量级对齐原版
精确命中93.88%需用户确认: 真实标的/日期/复权口径/当前价游标定义
三版(flame_A/B/C) 已加衰减参数, DECAY 可调
