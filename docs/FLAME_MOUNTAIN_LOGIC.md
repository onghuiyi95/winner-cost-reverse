## 结论 (分层)
- **成本分布 = 价格档直方图**: 11151 个价格桶, 每根K线成交按价格分桶累加 (CYQ 标准)
- **获利盘% = 截止价以下桶累计量 / 总累计量** (line 524 fVar2/(fVar2+fVar3))
- **N天前% = 把分布往前回溯 N 个周期再算获利盘**: 函数循环 **100 次** (对应 100天前~10天前),
  每次滚动一档计算历史快照获利盘 (line 255 iVar10=100, line 265 步进)
- **成本分布日期 = 截止日** (param_5=截止价, 对应图里"成本分布日期:20210312")
- **等权 vs 加权**: fVar2/fVar3 累加的是成交量(直方图加权) -> 与标准 TV WINNER 一致(加权)

## 与 winer_113.py 的关系
我们 winner_113.py 的 WINNER(P)=成本<=P占比 正是这套的简化版:
  dll: 11151桶成交量加权直方图, 循环100次算历史快照

差异: dll 用固定11151价格档(精细), py 用分位近似; dll 显式循环100次算N天前快照
