## 结论 (分层)
- **成本分布 = 价格档直方图**: 11151 个价格桶, 每根K线成交按价格分桶累加 (CYQ 标准)
- **获利盘% = 截止价以下桶累计量 / 总累计量** (line 524 fVar2/(fVar2+fVar3))
- **N天前% = 把分布往前回溯 N 个周期再算获利盘**: 函数循环 **100 次** (对应 100天前~10天前),
  每次滚动一档计算历史快照获利盘 (line 255 iVar10=100, line 265 步进)
- **成本分布日期 = 截止日** (param_5=截止价, 对应图里"成本分布日期:20210312")
- **等权 vs 加权**: fVar2/fVar3 累加的是成交量(直方图加权) -> 与标准 TV WINNER 一致(加权)

## 与 winer_113.py 的关系
我们 winner_113.py 的 WINNER(P)=成本<=P占比 正是这套的简化版:
  dll: 11151桶成交量加权直方图, 循环100次算历史快照

## "100次=100天" 误判修正
之前推断 "iVar10=100 循环 = 100天前" 是 **错的**. 精读 line 538-597 后修正:
- `iVar10=100` 循环 (line 543/579) 是 **单根K线内 1000 价格桶 / 10 = 100 组的组内聚合**
  (pdVar8+10 步进10个double, pdVar8[-1]..[8] 累加10桶) — 这是显示平滑, 不是天数
- **真正的 "N天前" 循环是外层**: iVar4 从 1 到 uVar9(=DAT_0113e2cc=回溯期数)
  每次写 DAT_0113e1c8[iVar4] = (累计/基准)*100
  iVar4=1 -> 最近期, iVar4=uVar9 -> 最远期 (你图 uVar9=10 即 10天前~100天前)
- 直方图内存布局: DAT_011289b8 = [K线序号][1000个价格桶] 二维数组
  (line 216: local_8*1000 + local_10, local_8=K线, local_10=价格桶0~999)

## 修正后结论 (最终)
- 成本分布 = 每根K线 1000 价格桶的成交量加权直方图 (11151桶是全局上限/窗口)
- 获利盘 = 截止价以下桶累计 / 总累计 (line 524 fVar2/(fVar2+fVar3))
- N天前% = 把直方图往前回溯 N 根K线(=N天) 再算获利盘, 由 uVar9 控制期数
- 成本分布日期 = 截止日 (param_5)
- 常量: 10000.0(价格精度) + 100.0(百分比) 已铁证
- "100次"=单根K线内桶聚合; "N天"=uVar9 外层循环 (运行时期数)
