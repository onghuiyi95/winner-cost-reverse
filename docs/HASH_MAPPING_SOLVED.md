# aiStack_1dc 哈希映射 — 破解结果 (2026-08-18)

## 破解结论: 这是日期→天数序号换算表, 不是价格桶表

### 铁证: aiStack_1dc[0..12] = 平年月度累计天数
```
[0]=0  [1]=0  [2]=31  [3]=59  [4]=90  [5]=120 [6]=151
[7]=181 [8]=212 [9]=243 [10]=273 [11]=304 [12]=334
```
对照平年每月1日是该年第几天 (0-based):
1月=0, 2月=31, 3月=59, 4月=90, 5月=120, 6月=151, 7月=181,
8月=212, 9月=243, 10月=273, 11月=304, 12月=334  ✓ 完全吻合

### 哈希公式 (costcore_100ccf00.c line 213-215)
```c
iVar5 = aiStack_1dc[iVar11] +                    // 月偏移 (月度表)
        ((uVar6 - 0x781 + ((uVar6-0x781)>>0x1f & 3)) >> 2) +  // (年-1921) 四舍五入/4
        uVar6 * 0x16d +                          // 年 * 365 (0x16d=365)
        -0xab313 +                               // 常量偏移 (0xab313=700691)
        iVar5 % 100;                             // 日
```
其中 uVar6=年 (iVar5/10000), iVar11=月 ((iVar5%10000)/100), 末项 iVar5%100=日.
→ 计算给定年月日 = 从某基准日 (1921年左右) 起的第几天序号.

### 用途 (line 205-265)

local_208 长度 = local_230 (K线总数), 按 K线序号索引 (line 253-256).
**不是价格桶.**
